# [PJT008] AI研究所

## 概要

AI まわりのアイデアを検証・試作・調査するための研究所。
使い捨て前提で小さく試し、育ったテーマだけを独立したプロジェクト／リポジトリへ切り出す。

## 構成

```
labs/     個別の実験。1テーマ1フォルダ
notes/    調査メモ・記録
```

## 進め方

- [ ] テーマを `labs/<theme>/` に切る
- [ ] 最小構成で動かして検証する
- [ ] わかったことを `notes/` に残す
- [ ] 育ったテーマは独立リポジトリへ切り出す

## ルール

- 実験は作り込みすぎない。動くことを最優先する
- テーマごとに `labs/<theme>/README.md` を置き、目的・やったこと・結果を残す
- 打ち切った実験も消さず、結論を README に書いて残す
